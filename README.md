# 🐍 Snake 3D Online - Jeu Multijoueur

Un jeu Snake 3D moderne avec système d'authentification, base de données et mini-map en temps réel.

## ✨ Fonctionnalités

- 🎮 **Jeu Snake 3D** avec graphismes Three.js avancés
- 👥 **Système d'authentification** complet (inscription/connexion)
- 💾 **Base de données simulée** stockée dans le repository GitHub
- 🗺️ **Mini-map 2D** en temps réel avec boussole
- 🏆 **Système d'achievements** avec progression
- 📱 **Contrôles tactiles** pour appareils mobiles
- 🎵 **Interface utilisateur** moderne et responsive
- ⚡ **Performances optimisées** avec animations fluides

## 🎯 Comment jouer

1. **Inscription/Connexion** : Créez un compte ou connectez-vous
2. **Menu principal** : Choisissez le mode de jeu
3. **Contrôles** :
   - `WASD` ou `Flèches` : Diriger le serpent
   - `Espace` : Pause/Reprendre
   - `R` : Redémarrer (en pause)
   - `Échap` : Retour au menu
4. **Objectif** : Collectez la nourriture dorée pour grandir
5. **Évitez** : Les murs et votre propre corps

## 🏆 Achievements

- 🎮 **Premier Pas** : Jouer votre première partie
- 💯 **Centurion** : Atteindre 100 points
- 🐍 **Serpent Géant** : Atteindre une longueur de 10
- ⚡ **Maître de Vitesse** : Atteindre le niveau 5
- 🛡️ **Survivant** : Jouer pendant 2 minutes
- ⭐ **Perfectionniste** : Score parfait de 500 points

## 🛠️ Technologies utilisées

- **Three.js** : Rendu 3D et animations

- **CSS3** : Interface utilisateur moderne
